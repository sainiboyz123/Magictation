# Changelog

## 0.2.0
- New free canvas: place When / And / Then cards anywhere and draw lines between them.
- And cards have a Yes and a No output, so each answer can lead to its own cards.
- One output can feed several cards (they run in parallel); several When cards can start different paths.
- Pick a device first, then what it should do. One tile per device; battery, signal, firmware and other diagnostic entities are hidden.
- Apps for things that are not a device: Date & time, Presence, Notifications, Timers & flow, Scenes, Home Assistant.
- Bigger, easier-to-read text everywhere. Clean light look, dark mode follows your system.
- Test mode shows the path the flow would take right now.
- Flows from 0.1 (WHEN / AND / THEN columns) are not supported; recreate them on the canvas.

## 0.1.0
- First release: visual flow builder, native automation deployment, live states, test mode, YAML preview.
